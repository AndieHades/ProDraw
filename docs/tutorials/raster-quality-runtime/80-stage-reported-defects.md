# Stage `Q8`: дефекты, названные пользователем при приёмке

- Status: `in_progress`
- Depends on: `Q4`
- Requirements: `RQ-BRUSH-01`, `RQ-PAR-01`

Список ведётся в порядке, заданном пользователем: сначала кисти, затем
остальной интерфейс. Ни один пункт не закрывается без наблюдаемой проверки.

## Дефекты

| ID | Дефект | Формулировка пользователя | Статус |
| --- | --- | --- | --- |
| `D1` | кисть не оставляет отпечатка на слое | «проводишь линию она видна пока ведёшь — но не остаётся» | in_progress |
| `D2` | штрих сохраняется не всегда, иногда исчезает сразу | «штрих сохраняется не всегда, иногда сразу исчезает» | in_progress |
| `D3` | ход идёт отдельными оттисками, а не плавной линией | «кисти рисуют не плавно, а квадратами оттисков, рубленной лестницей» | in_progress |
| `D4` | у кистей нет превью | «у кистей вообще нет превью» | open |
| `D5` | исчезли тултипы ко всем кнопкам | «исчезли тултипы ко всем кнопкам» | open |
| `D6` | галерея кистей без отступов и без шапки, как в палитре | «сама галерея кистей по дизайну уродская, нет отступов и шапка как в палитре» | open |
| `D7` | нет кнопок дублирования и удаления кистей | «кнопок для дублирования и удаления кистей» | open |

## Порядок

`D1`–`D3` — один дефект пути рисования и чинятся вместе. `D4` идёт следом,
потому что превью читается тем же движком дабов. `D5`–`D7` — интерфейс, после
кистей.

## Contracts

- Ход, доведённый до `pointerup`, остаётся на слое и попадает в один шаг Undo.
- Между дабами нет видимых разрывов на размерах кисти от `1` до `160 px`.
- Превью кисти рисуется тем же движком, что и ход, а не подписью из имени.
- У каждой кнопки оболочки есть локализованный тултип.
- Панель кистей повторяет отступы и шапку панели палитры.

## Checks

- Фокусные: `tests/brush`, `tests/stroke`, `tests/systems/draw`.
- Регрессия на реальном пути ввода: pointer-события с выбранным пресетом.
- `npm run validate`; `npm run package:mac` перед приёмкой.

## Acceptance criteria

- [ ] `D1`–`D3` закрыты тестом, который ведёт ход через реальный ввод.
- [ ] `D4` показывает штрих пресета, а не первую букву имени.
- [ ] `D5` восстановлен на всех кнопках оболочки.
- [ ] `D6` и `D7` подтверждены пользователем в собранном приложении.
