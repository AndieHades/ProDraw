# Stage `Q8`: дефекты, названные пользователем при приёмке

- Status: `in_progress`
- Depends on: `Q4`
- Requirements: `RQ-BRUSH-01`, `RQ-PAR-01`

Список ведётся в порядке, заданном пользователем: сначала кисти, затем
остальной интерфейс. Ни один пункт не закрывается без наблюдаемой проверки.

## Дефекты

| ID | Дефект | Формулировка пользователя | Статус |
| --- | --- | --- | --- |
| `D1` | кисть не оставляет отпечатка на слое | «проводишь линию она видна пока ведёшь — но не остаётся» | fixed |
| `D2` | штрих сохраняется не всегда, иногда исчезает сразу | «штрих сохраняется не всегда, иногда сразу исчезает» | fixed |
| `D3` | ход идёт отдельными оттисками, а не плавной линией | «кисти рисуют не плавно, а квадратами оттисков, рубленной лестницей» | fixed |
| `D3a` | отпечаток не поворачивается по ходу движения | «поворачивать штамп по ходу движения кисти и создавать плавные линии» | fixed |
| `D4` | у кистей нет превью | «у кистей вообще нет превью» | fixed |
| `D5` | исчезли тултипы ко всем кнопкам | «исчезли тултипы ко всем кнопкам» | fixed |
| `D6` | галерея кистей без отступов и без шапки, как в палитре | «сама галерея кистей по дизайну уродская, нет отступов и шапка как в палитре» | fixed |
| `D7` | нет кнопок дублирования и удаления кистей | «кнопок для дублирования и удаления кистей» | fixed |

## Порядок

`D1`–`D3` — один дефект пути рисования и чинятся вместе. `D4` идёт следом,
потому что превью читается тем же движком дабов. `D5`–`D7` — интерфейс, после
кистей.

## Что сделано

- `D1`/`D2`: потеря фокуса окна и потеря захвата указателя вызывали ту же
  отмену, что и `pointercancel`: тайлы откатывались, шаг истории не
  записывался. Прерывание теперь завершает ход, отменяет только сам указатель
  и смена документа — `src/systems/input/index.js`, тест
  `tests/input/strokeInterruption.test.js`.
- `D3`: твёрдый отпечаток был бинарной маской по целым клеткам, а отрезок между
  сэмплами укладывался Брезенхемом. Отпечаток считает покрытие пикселя по
  расстоянию до субпиксельного центра, путь идёт шагом меньше радиуса —
  `src/systems/draw/soft-tip.ts`, тест `tests/stroke/softTipPath.test.js`.
- `D3a`: поворот отпечатка умножался на `shape.rotation` пресета, а он нулевой
  у большинства кистей — вытянутый отпечаток ставился под одним углом. Теперь
  отпечаток идёт по ходу кисти, отказаться может только `orientToScreen` —
  `src/logic/stroke/StrokePipeline.ts`, тест
  `tests/stroke/dabFollowsStroke.test.ts`. Эталоны `brushGoldenPlans`
  перезаписаны.
- `D4`: превью рисует движок кисти в плитку панели —
  `src/systems/draw/brush-preview.ts`, `brush-tile.ts`.
- `D5`: нативный тултип Chromium молчит после ввода пером, поэтому оболочка
  показывает свой из того же `title` — `src/systems/tooltip.ts`.
- `D6`: у панели появились шапка с заголовком и закрытием, отступы тела и
  строка действий — как в окне палитры.
- `D7`: дублирование делает пользовательскую копию со своим именем, размером и
  непрозрачностью; удаление доступно только для копии — встроенные пресеты
  поставляются с приложением и не удаляются
  (`src/systems/draw/brush-library-store.ts`).

## Contracts

- Ход, доведённый до `pointerup`, остаётся на слое и попадает в один шаг Undo.
- Между дабами нет видимых разрывов на размерах кисти от `1` до `160 px`.
- Превью кисти рисуется тем же движком, что и ход, а не подписью из имени.
- У каждой кнопки оболочки есть локализованный тултип.
- Панель кистей повторяет отступы и шапку панели палитры.

## Checks

- Фокусные: `tests/brush`, `tests/stroke`, `tests/systems/draw`.
- Регрессия на реальном пути ввода: pointer-события с выбранным пресетом.
- `npm run validate`; `npm run package:mac` перед приёмкой.

## Acceptance criteria

- [ ] `D1`–`D3` закрыты тестом, который ведёт ход через реальный ввод.
- [ ] `D4` показывает штрих пресета, а не первую букву имени.
- [ ] `D5` восстановлен на всех кнопках оболочки.
- [ ] `D6` и `D7` подтверждены пользователем в собранном приложении.
