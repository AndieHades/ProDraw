## Contracts

- Один кадр — один `requestAnimationFrame`; прямых синхронных `render()` из
  систем нет.
- Ресайз окна сохраняет `S.view.zoom`, `ox`, `oy`; подгонка вида остаётся
  явной командой.
- Композит не аллоцирует полноразмерный canvas на кадр.
- Панель слоёв обновляет затронутые строки; полная пересборка допускается
  только при изменении структуры дерева.
- Миниатюра слоя перерисовывается только при смене ревизии слоя.

## Steps

1. Вынести `fxGroups`, `isolatedGroups` и раскладку по индексам в один
   предрасчёт на кадр; в цикле по слоям остаются только просмотры массива.
2. Кэшировать `folderChain` и `opacityFor` на кадр по идентификатору папки.
3. Ввести пул поверхностей для `isolatedSurface` с ограничением по числу и
   освобождением при смене размера документа.
4. Заменить `window.addEventListener('resize', fitView)` на обработчик,
   который синхронизирует размер холста и просит `requestRender()`.
5. Перевести оставшиеся прямые вызовы `render()` на `requestRender()`; оставить
   синхронный путь только там, где он доказуемо нужен.
6. Переписать `layList` на инкрементальное обновление: сравнение с текущим
   DOM, обновление только изменившихся строк, делегированные слушатели вместо
   привязки на каждую строку.
7. Кэшировать миниатюру слоя по `layerRev`.
8. Свести пары `getImageData` источника и назначения к одному чтению там, где
   назначение можно собрать в буфере до `putImageData`.
9. Проверить, что `imageSmoothingQuality = 'high'` не включается на масштабах,
   где он не даёт видимой разницы.

## Edge and failure cases

- Пул поверхностей и смена размера документа: старые поверхности обязаны
  освобождаться, иначе пул станет утечкой.
- Инкрементальная панель слоёв и drag-and-drop строк: перетаскивание не должно
  ломаться на частичном обновлении.
- Инлайн-переименование во время обновления списка: фокус и каретка
  сохраняются.
- Ресайз при активной трансформации или Crop: рамка не должна разъезжаться.
- Кэш миниатюры и Undo: ревизия обязана меняться при откате.
