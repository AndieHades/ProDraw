# Stage `Q3`: coalesced ввод с pressure и tilt

- Status: `draft`
- Depends on: `Q2B`
- Requirements: `RQ-IN-01`, `RQ-PERF-01`

## Scope

Продакшн перестаёт терять сэмплы пера и начинает читать давление и наклон.
Ввод отделяется от инструмента типизированным сэмплом. Кисти этот этап ещё не
подключает — это `Q4`.

## Change map

| Путь | Изменение |
| --- | --- |
| `src/systems/input/index.js` | читает coalesced события, отдаёт типизированный сэмпл |
| `src/core/input/actualPointerEvents.ts` | переиспользуется продакшном |
| `src/contracts/` | контракт `PointerSample` доступен живой оболочке |
| `src/systems/input/gestures.js` | тач-путь отдаёт тот же сэмпл |
| `src/systems/draw/*` | инструменты принимают сэмпл, а не `PointerEvent` |
| `src/config/` | fallback давления для мыши и пальца как данные |

## Contracts

- `PointerSample`: `x`, `y`, `pressure`, `tiltX`, `tiltY`, `pointerType`,
  `timeStamp`. Сериализуем, без DOM.
- `down`/`move`/`up` разворачивают `getCoalescedEvents()` и передают каждый
  сэмпл планировщику в исходном порядке.
- Мышь и палец получают фиксированное давление из `src/config`, а не ноль.
- `getBoundingClientRect()` кэшируется на время хода и инвалидируется по
  ресайзу и скроллу, а не читается на каждом событии.
- Курсор пишется только при смене значения.

## Steps

1. Вынести контракт `PointerSample` туда, где его видят и живая оболочка, и
   существующий `actualPointerEvents.ts`.
2. В `systems/input` развернуть coalesced события в `move`; сохранить порядок и
   не терять последний сэмпл перед `up`.
3. Прокинуть `pressure`, `tiltX`, `tiltY` в сэмпл; мышь и палец берут fallback
   из конфигурации.
4. Кэшировать прямоугольник холста на время хода; инвалидировать по `resize` и
   изменению layout.
5. Записывать `cv().style.cursor` только при фактической смене.
6. Убрать hover-работу из `move`, пока идёт рисование.
7. Перевести инструменты рисования на приём сэмпла.
8. Добавить синтетический trace: `240` сэмплов в секунду с меняющимся давлением
   и наклоном; тест доказывает, что ни один сэмпл не потерян и что p95
   «сэмпл → готовая frame model» держится в бюджете.

## Edge and failure cases

- `getCoalescedEvents` отсутствует: fallback на одиночное событие, поведение не
  хуже текущего.
- Перо ушло за край окна при захвате указателя: последний сэмпл всё равно
  доходит до `up`.
- Планшет отдаёт `pressure === 0` при контакте: значение нормализуется, а не
  превращает штрих в пустой.
- Смешанный ввод (палец жестом во время пера): жест не должен красть сэмплы
  активного хода.
- Ластик пера (`pointerType === 'pen'`, кнопка ластика) остаётся отдельной
  веткой и не ломает `pen-button.js`.
