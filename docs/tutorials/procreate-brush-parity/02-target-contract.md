# 02 — Целевой контракт

## Что значит «1 в 1»

Совпадение проверяется на растре, а не на списке настроек. Эталон — PNG-экспорт
штриха из Procreate на прозрачном фоне, чёрным цветом, на холсте известного
размера.

Штрих ProDraw считается совпавшим, если при одинаковых входных данных
(траектория, нажим, наклон, размер и непрозрачность слайдеров, размер холста):

| Метрика | Порог |
| --- | --- |
| Средняя абсолютная разница альфы | ≤ 0.02 |
| 99-й перцентиль разницы альфы | ≤ 0.10 |
| Разница покрытой площади (alpha > 0.5) | ≤ 2 % |
| Разница средней ширины штриха | ≤ 0.5 px |
| Смещение центральной линии | ≤ 0.5 px |

Пороги — стартовые. Первый прогон гармонизирует их с реально достижимым и
фиксирует в [`90-verification.md`](90-verification.md).

Стохастические части (jitter, scatter, randomise) сравниваются не попиксельно, а
по распределению: средняя альфа в скользящем окне 8×8 и её дисперсия.

## Входные контракты

- Декодер `.brush` обязан различать три состояния источника формы/зерна:
  `embedded` (ассет лежит в архиве), `resolved` (найден в библиотеке
  источников `src/app-folders/brush-sources/`), `missing` (не найден).
  `missing` не подменяется процедурной картинкой молча — состояние доходит до
  `BrushCompatibilityReport` и до Brush Studio.
- Процедурных генераторов формы и зерна в движке не остаётся: источник либо
  настоящий, либо отсутствует. Исключение — радиальный кончик как быстрый
  путь рендера, и только если он совпал с настоящим ассетом по порогам выше.
- `paintSize` и `paintOpacity` восстанавливают положение слайдеров при выборе
  кисти; пользователь может их переопределить, и переопределение переживает
  перевыбор кисти.
- Домен размера: слайдер `0..1` отображается в пиксели через
  `minSize..maxSize` пресета с калиброванным коэффициентом к размеру холста,
  а не через магическую константу.
- Кривые `dynamicsPressure*Curve` читаются как монотонные кусочные кривые по
  контрольным точкам и применяются до всех остальных множителей.
- `minOpacity`/`maxOpacity` и `minSize`/`maxSize` — концы отображения нажима,
  а не clamp поверх результата.

## Контракт рендера штриха

- Один штрих накапливается в одном буфере покрытия и композитится на слой один
  раз при завершении; промежуточные кадры показывают тот же буфер, а не
  дополнительные наложения.
- Самопересечение штриха при непрозрачности < 1 не темнеет.
- Хвостовой taper применяется по фактическому концу штриха, а не по нажиму.
- `spacing = 0` в архиве означает непрерывный след, а не «1 % диаметра».

## Что остаётся вне контракта

Явно не покрывается и остаётся в `excludedSections`:

- wet mix, bleed, load, mixing;
- color dynamics (hue/saturation/brightness/darkness/secondary color);
- materials (metallic, roughness, height), burnt edges, wet edges;
- roll-параметры пера (`Valkyrie*RollParameters`) — Windows-перо их не даёт.

Эти секции обязаны быть перечислены поимённо в отчёте совместимости, чтобы
расхождение по ним не выглядело багом.

## Наблюдаемость

`BrushCompatibilityReport` расширяется полями `shapeSourceState`,
`grainSourceState` и `missingSourceNames`. Brush Studio показывает их в панели
источников, а `unsupportedActiveFields` остаётся честным списком того, что
файл просит, а движок не делает.

## Библиотека и app preferences

- Карточка сначала использует versioned cached RGBA preview и только при cache
  miss ставит decode/render в bounded background queue.
- Закрытие и повторное открытие панели не инвалидирует previews неизменённых
  `brush.id@revision`; изменение renderer/source version инвалидирует их явно.
- Последняя выбранная кисть восстанавливается только если её id ещё существует;
  иначе выбирается `lineart`, а при его отсутствии первая доступная без ошибки.
- Последний активный RGB хранится как app preference, не как часть документа.
  Битая или недоступная запись даёт штатный цвет по умолчанию.
- Компактная библиотека закрывается только своим крестиком или повторной
  командой toggle; pointerdown вне окна не меняет её видимость.
- Brush shortcut хранит нормализованное keyboard combo. Конфликт не запускает
  две кисти: новое назначение становится владельцем combo, старое снимается.
