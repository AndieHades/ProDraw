# 90 — Верификация

## Протокол эталонов

Эталоны снимаются в Procreate один раз и живут в
`tests/brush-parity/reference/<brush-id>/<fixture>.png`.

1. Холст 2048×2048, фон прозрачный, один слой на штрих.
2. Кисть выбирается из библиотеки без изменения слайдеров: размер и
   непрозрачность остаются такими, какими их сохранил автор
   (`paintSize`, `paintOpacity` из архива).
3. Цвет — чистый чёрный `#000000`.
4. Фикстуры:
   - `straight` — горизонталь через центр, ровный нажим;
   - `wedge` — горизонталь с нарастанием нажима от минимума к максимуму;
   - `arc` — дуга 180° радиусом 600 px;
   - `figure-eight` — самопересечение, для проверки накопления;
   - `tap` — одиночное касание в центре.
5. Экспорт PNG без фона, без сжатия с потерями.
6. Рядом кладётся `meta.json`: id кисти, размер холста, положение слайдеров,
   тип ввода (`pen`/`touch`), примечания по траектории.

Траектория и нажим известны приближённо, поэтому попиксельная разница —
не единственная метрика; см. `D-2` в
[`03-decisions-and-risks.md`](03-decisions-and-risks.md).

## Метрики и пороги

Стартовые пороги — из [`02-target-contract.md`](02-target-contract.md).
После `PBP-1` они пересматриваются один раз по фактически достижимому и
дальше не смягчаются без записи в этот файл.

| Метрика | Порог | Устойчива к траектории |
| --- | --- | --- |
| Средняя разница альфы | ≤ 0.02 | нет |
| p99 разницы альфы | ≤ 0.10 | нет |
| Разница площади (alpha > 0.5) | ≤ 2 % | да |
| Разница средней ширины | ≤ 0.5 px | да |
| Смещение центральной линии | ≤ 0.5 px | да |
| Разница дисперсии в окне 8×8 | ≤ 15 % | да |

Для фикстур с заметной случайностью решающими считаются устойчивые метрики.

## Гейты по этапам

Минимальный достаточный gate по
[`docs/project/validation-policy.md`](../../project/validation-policy.md);
строка «drawing/input/brush» требует focused integration + browser smoke +
check/lint.

| Этап | Обязательные проверки |
| --- | --- |
| `PBP-1` | `vitest run tests/brush-parity`, `npm run check`, targeted lint |
| `PBP-2` | + `validate:lines`, `validate:cycles`, browser smoke |
| `PBP-3` | + `npm run test:performance`, визуальный прогон 12 бандлов |
| `PBP-4` | + round-trip пресетов, smoke пером с нажимом |
| `PBP-5` | + `tests/history`, smoke: пересечение, отмена, ластик, симметрия |
| `PBP-6` | preview cache unit/integration + open/close browser timing smoke |
| `PBP-7` | web/desktop preference round-trip + missing-brush/corrupt-color cases |
| `PBP-8` | floating-window outside click + shortcut conflict/restart/input guards |

Перед каждым коммитом — `git diff --check` и перечитанный `git status`.
Пропущенные проверки называются точным именем и причиной.

## Регресс по остальным кистям

`PBP-3` и `PBP-5` меняют общий движок, поэтому после них прогоняется
визуальная проверка всех двенадцати бандлов из
`src/app-folders/brushes/main/`. Пять кистей с ассетами внутри архива
(`freckles`, `gundersen`, `pencil_waxy`, `net_screentone`, `screentone`) —
самая чувствительная группа: у них форма и зерно уже настоящие, и любое
изменение домена видно сразу.

## Что считается провалом

- Метрика улучшилась на `lineart`, но ухудшилась хотя бы на одной другой кисти
  без явного объяснения в completion record.
- Улучшение получено подгонкой константы под одну фикстуру.
- Отсутствующий ассет снова подменяется чем-либо молча, без состояния
  `missing` в отчёте совместимости.
- `unsupportedActiveFields` сократился без реализации — то есть ключ просто
  переехал в `supported` или под `excluded`-регулярку.
