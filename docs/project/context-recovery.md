# Восстановление контекста

1. Прочитать `AGENTS.md`, `docs/index.md`, roadmap и живой план.
2. Найти в плане `Resume Here`; не доверять ему без проверки.
3. Выполнить `git status --short --branch`, `git log -5 --oneline`.
4. Сверить указанные commits/checks/working paths с кодом и тестами.
5. Перечитать главу текущего этапа и `90-verification.md`.
6. Если branch или paths разошлись, обновить evidence и plan до реализации.
7. Продолжить ровно с `Next action`; несвязанные идеи отправить в inbox.
