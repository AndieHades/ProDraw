# Agent hooks

`.claude/hooks/session-start.mjs` выдаёт короткие напоминания: прочитать
канонические правила, восстановить контекст, соблюдать границы и line limit,
вести живой план, использовать TypeScript и запускать подходящий gate.

Hook не копирует rule packs. При смене правил сначала обновляется канонический
документ, затем entrypoint и только потом короткое напоминание hook.
