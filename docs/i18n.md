# Локализация

Видимый текст хранится только в locale data и вызывается через `t(key, vars)`.
Русский и английский ключи регистрируются вместе; fallback возвращает ключ, чтобы
пропуск был заметен. Имена пользовательских документов/кистей не переводятся.

Current production layout:

```text
src/i18n/raster/translate.ts
src/i18n/raster/ru.ts
src/i18n/raster/en.ts
```

Brush compatibility, save/import failures, memory limits и desktop permissions
обязаны иметь локализованные сообщения. Валидатор parity/hardcoded text входит
в `R1/R2`.

Legacy JS locales не загружаются production entrypoint и будут удалены в R6.
