# AGENTS.md — правила работы с ProDraw

ProDraw — Windows-first touch/pen растровый редактор с профессиональным движком
кистей. Vite/web — проверяемый development runtime, а конечная поставка —
desktop-приложение. Продуктовый ориентир: скорость и жесты Procreate, точность
слоёв, выделений и экспорта Photoshop. Пиксель-арт и pixelizer больше не
определяют архитектуру продукта.

## Непереговорные правила

- Рабочие TypeScript/JavaScript/CSS/config-файлы — не более 150 строк.
- Один модуль решает одну задачу; не ужимай код ради лимита, разделяй его.
- `logic` содержит чистые вычисления; `core` — контракты и сервисы; `systems`
  оркестрируют один процесс; `ui` только отображает состояние и посылает команды.
- Системы не импортируют другие системы. Связь — типизированные команды,
  события и явные core-контракты.
- Документ хранит полноцветные RGBA-слои. Сетка пиксель-арта не является
  канонической моделью и не должна возвращаться через совместимость.
- Ввод пера сохраняет pressure/tilt; мышь и touch имеют предсказуемые fallback.
- View zoom/rotation не меняют RGBA. Transform/Liquify строятся от неизменного
  source snapshot и выполняют не более одного destructive resample на Apply.
- Пользовательский текст идёт через i18n, стили — через theme tokens,
  настраиваемые числа — через `src/config`.
- Ошибка отдельной кисти или необязательного обработчика не должна ронять app.
- Не трогай несвязанные пользовательские изменения.
- Проверяй изменение минимальным достаточным gate из
  `docs/project/validation-policy.md`.

## Git

- До коммита перечитай `git status` и task-owned diff.
- Перед коммитом выполни `git fetch origin main`; если `main` ушёл вперёд,
  перенеси работу поверх него и повтори проверки.
- Один завершённый этап плана — один сфокусированный коммит.
- Не создавай pull request. После коммита отправляй текущую рабочую ветку.

## Desktop-сдача

Целевая платформа сдачи — macOS (`project.config.json.targetPlatform`).

- Рабочая сборка сдаётся только через постоянный путь
  `/Applications/ProDraw.app`.
- Для локальной сдачи запускай `npm run package:mac` без `CI`: этот путь должен
  получить новую сборку и пройти packaged renderer smoke.
- `CI=1` и `artifacts/desktop` допустимы только как промежуточная staging-сборка;
  нельзя называть её сданной или просить пользователя запускать вместо
  `/Applications/ProDraw.app`.
- До отчёта проверь время файла бандла и что smoke запускался именно для этого
  исполняемого файла. Если цель заблокирована запущенным ProDraw, не завершай
  пользовательский процесс: подготовь staging и доведи обновление после
  освобождения цели.
- Windows-сборка остаётся доступной через `npm run package:desktop`, но не
  является условием приёмки этапа.
